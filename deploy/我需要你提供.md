## 必需（3 项）

### 1. SSH 密钥文件在本机的路径

创建 ECS 时下载的 `.pem` 文件，例如：

```
C:\Users\JD\Downloads\aliyun-ecs.pem
```

**不要把密钥内容粘贴到聊天里**，只告诉我**完整路径**。  
我会在你电脑上执行 `ssh` 登录 ECS（118.31.109.161）。

### 2. ECS 登录用户名

一般是下面之一（看阿里云控制台「远程连接」提示）：

- `root`
- `ecs-user`

回复我一个即可。

### 3. API 端口（安全组）

二选一回复：

- **A**：我已安全组添加 **TCP 5000**（推荐）
- **B**：用已有 **8000** 端口，不要 5000
